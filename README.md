# ReThread 👕♻️

ReThread is a full-stack fashion and wardrobe management platform that helps users organize clothes, plan outfits, manage shopping activities, and simplify wardrobe handling digitally.

---

## 🚀 Features

- User Authentication & Login System
- Digital Wardrobe Management
- Outfit Planning
- Product Selling & Shopping Pages
- Admin Dashboard
- Backend API Integration
- Organized Clothing Categories
- Responsive Frontend Design
- Database Connectivity
- Secure Middleware Handling

---

## 🛠️ Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js

## ⚙️ Installation & Setup

### Clone the Repository

```bash
git clone https://github.com/aryashinde2811-pixel/ReThread.git
```

### Navigate to Project Folder

```bash
cd ReThread
```

### Install Dependencies

```bash
npm install
```

### Start Backend Server

```bash
node server/server.js
```
